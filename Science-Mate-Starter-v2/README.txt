SCIENCE MATE - 화면 전환 테스트

[실행 방법]
1. 압축을 풀고 폴더를 VS Code에서 엽니다.
2. index.html 파일에서 마우스 오른쪽 버튼을 누릅니다.
3. "Open with Live Server"를 선택합니다.

[테스트 순서]
1. 시작 화면의 "-PRESS ANY KEY TO START-"를 클릭합니다.
   (키보드의 아무 키를 눌러도 시작됩니다.)
2. 두 번째 화면 오른쪽의 E.CIRCUIT 영역을 클릭합니다.
3. PDF 3페이지의 E.CIRCUIT 주제 선택 화면이 표시되는지 확인합니다.

[현재 구현된 화면]
1페이지: 시작 화면
2페이지: CHEMISTRY / PHYSICS / E.CIRCUIT 분야 선택 화면
3페이지: E.CIRCUIT 주제 선택 화면
