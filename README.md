# Science Mate integration

Run Node.js 22 LTS, then `npm install`, `npm run dev`. Open the URL printed by Vite. For production: `npm run build`, then `npm run preview`.

The original React physics components and chemistry page are retained; the existing E.CIRCUIT screen and controls are used as the main shell. Legacy starter directories remain for history. Review all five simulations before merging. Hooke energy model remains unchanged and needs subject-owner review. No browser execution has been verified by this integration.
