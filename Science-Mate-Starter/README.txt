SCIENCE MATE - 첫 화면 전환 테스트

[실행 방법]
1. 압축을 푼 폴더를 VS Code에서 엽니다.
2. index.html 파일을 엽니다.
3. Live Server 확장 프로그램이 설치되어 있다면,
   index.html에서 마우스 오른쪽 버튼을 누르고
   "Open with Live Server"를 선택합니다.
4. 시작 화면의 "-PRESS ANY KEY TO START-" 문구를 클릭합니다.
   키보드의 아무 키를 눌러도 다음 화면으로 넘어갑니다.

[파일 구조]
index.html              웹페이지의 화면 구조
css/style.css           화면 크기, 배치, 전환 효과
js/main.js              클릭/키보드 입력과 화면 전환 동작
images/start-screen.png PDF 1페이지 시작 화면 이미지
images/category-screen.png  PDF 2페이지 분야 선택 화면 이미지

[참고]
현재는 디자인과 첫 화면 전환만 구현한 초기 버전입니다.
두 번째 화면의 CHEMISTRY / PHYSICS / E.CIRCUIT 버튼 동작은
다음 개발 단계에서 구현할 예정입니다.
